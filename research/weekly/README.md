# 주간 AI 활용 리서치

매주 월요일 아침 예약 작업이 조사해서 `YYYY-MM-DD.md` 로 하나씩 추가한다. 최신 파일명이 가장 늦은 날짜.

각 파일 구성:
1. 이번 주 꼭 볼 것 TOP 3
2. 주제별 항목 — Claude 스킬·플러그인 / 디자인·UI / 업무 자동화 / 프롬프트·작업 방식
   - 항목명 · 한 줄 요약 · 어디에 쓸지 · 다음에 할 일 · 점수(관련성/난이도/신뢰도) · 원문 링크
3. 모델 순위 변화 (ASAP 리더보드, 원출처 Artificial Analysis 교차 확인)
4. 보안 메모
5. 지난주 대비 바뀐 것
