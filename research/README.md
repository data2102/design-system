다른 세션에서 꺼내 쓰라고 모아 두는 조사 결과. 화면을 만들거나 점검하기 전에 여기를 먼저 읽는다.

## 파일

| 파일 | 내용 | 언제 읽나 |

| [`ai-tells.md`](ai-tells.md) | AI 티 체크리스트 (화면·문구·신뢰·코드 신호 + 여백식 처방 + 검증법) | 새 화면·랜딩을 만들 때, 점검할 때 |
